# Image assets

The following original concept photographs were generated using the built-in image-generation tool and saved locally as optimized JPEGs. They depict fictional spaces, not verified listings. No API key or CLI fallback was used.

## images/courtyard-villa.jpg

Final prompt:

> Use case: photorealistic-natural. Asset type: architectural photography for a premium real estate website demo. Primary request: a beautiful contemporary two-story tropical courtyard villa with warm ivory limestone, natural oak screens, huge glass windows, a calm rectangular swimming pool and sculptural lush greenery. Scene: quiet upscale tropical residential neighborhood, no recognizable real location. Composition: wide landscape 3:2 architectural editorial photograph from the garden, house occupies center and right, clean foreground pool and olive green planting. Lighting: soft late afternoon sunlight, elegant lived-in atmosphere, realistic material texture. Magazine-quality architectural photography, restrained warm natural colors. No people, no logos, no text, no watermark.
